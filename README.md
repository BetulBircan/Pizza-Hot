# Pizza Hot Projesi
Bu proje pizza siparişi kaydedilmesi için oluşturuldu.
### Kullanılan Programlar
- Node.js
- React
- Context Api/ Reducer
- Bootstrap

### Projenin Çalıştırılması
**pizza-api** Dosyası: Burada ürünlerin listelenmesi, sepete eklenmesi, siparişlerin kaydedilmesi vb işlemlerin gerçekleştirilmesi için yazılan isteklerin
servisleri (Backend Servisi) mevcuttur.
`npm run start` komutu ile çalıştırılması gereklidir.

**pizza-hot** Dosyası : Burada da projenin ön yüzü mevcuttur.
`npm run dev` komutu ile çalıştırılması gereklidir.

## Anasayfa
Burada pizzalar listelenir, anasayfanın tema rengi değiştirilebilir, açık tema,koyu tema yapılabilir, sepete ürün eklenebilir ve sepete eklenen ürünler gösterilir.
